# Milestone e Definition of Done

## Milestone M1: MVP Funzionale (Q1 2025)

### Obiettivo
Prototipo dimostrabile con dashboard, creazione richieste budget e workflow approvazioni base.

### User Stories incluse
- Dashboard con KPI reali da DB
- Form creazione richiesta budget
- Visualizzazione lista richieste
- Workflow approvazioni base (aggiornamento stato)

### Definition of Done
- [ ] Tutte le funzionalità Must Have completate
- [ ] Test manuali passati (login, dashboard, creazione richiesta, approvazione)
- [ ] Nessun errore critico in console
- [ ] Build di produzione funzionante
- [ ] Documentazione utente base (README aggiornato)

### Criteri di Accettazione per ogni story
1. Funzionalità implementata e testabile
2. UI coerente con design system esistente
3. Validazione input lato client e server
4. Messaggi di errore chiari all'utente
5. Guardie RBAC applicate correttamente

## Milestone M2: UI/UX Completo (Q2 2025)

### Obiettivo
Miglioramento interfaccia con componenti riusabili, layout responsive e accessibilità.

### Deliverable
- UI kit completo (Button, Input, Card, Modal, Table)
- Layout responsive (mobile, tablet, desktop)
- Accessibilità WCAG 2.1 AA
- Dark mode opzionale

### Definition of Done
- [ ] Tutte le pagine responsive
- [ ] Controlli accessibilità passati (screen reader, keyboard navigation)
- [ ] Contrasti colori conformi WCAG
- [ ] Componenti riutilizzati in tutto il codebase

## Milestone M3: Feature Complete v1.0 (Q3 2025)

### Obiettivo
Rilascio v1.0 con ricerca avanzata, export e report.

### Deliverable
- Ricerca e filtri avanzati
- Export CSV/PDF
- Report dashboard

### Definition of Done
- [ ] Tutte le funzionalità Should Have completate
- [ ] Performance accettabile (<2s caricamento dashboard)
- [ ] Test end-to-end principali passati
- [ ] Documentazione completa (user guide, API docs)

## Note Generali

### Processo di Validazione
1. Code review obbligatoria
2. Test manuali su browser principali (Chrome, Firefox, Safari)
3. Verifica conformità design system
4. Checklist Definition of Done verificata

### Metrica Successo
- Zero bug critici (P0/P1)
- Feedback positivo da stakeholder su demo
- Tempo di caricamento <2s per pagine principali
